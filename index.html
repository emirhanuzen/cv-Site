Hakkımda

Yazılım Mühendisliği 4. sınıf öğrencisi ve ölçeklenebilir sistemlere odaklanan bir Backend Geliştiriciyim. Python (FastAPI), PostgreSQL ve yöneticileriyle asenkron (RabbitMQ/Celery) katmanlı (layered) ve olay güdümlü (event-driven) backend mimarileri tasarlıyor; büyük veri (Big Data) işleme ve doğrulama süreçlerini Geliştirdiğim sistemleri konteynerleştirerek yönetiyorum. Docker ile üretim ortamına entegre ediyorum. Ayrıca Java ve C# ile nesne yönelimli (OOP) kurumsal mimariler geliştiriyorum. Arka uç yetkinliklerimi; Flutter ile çapraz platform projeler, NLP (Voice to Action) otomasyonları ve özel ML modellerinin backend entegrasyonuyla destekliyorum. Aktif TEKNOFEST sürecimizde Scrum Master olarak Çevik (Agile) metodolojileri yönetiyor; hata toleransı yüksek ve veri odaklı yazılım mimarileri inşa ediyorum.

Python (FastAPI, Flask) Java (Spring) C# PostgreSQL / MongoDB / MS SQL RabbitMQ & Celery Docker Git Flutter
